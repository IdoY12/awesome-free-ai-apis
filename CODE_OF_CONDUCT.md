# Code of Conduct

This is a small project about facts: which AI APIs are free, and on what terms. The rules for taking part are short.

## What we expect

- **Be kind.** Disagree with the claim, not the person. No insults, harassment or personal attacks, in issues, pull requests or review comments.
- **Assume good faith.** Most wrong entries are stale, not malicious. Point to the page that shows the current state.
- **Cite sources.** A disagreement about a limit, a policy or whether a tier is "permanent" is settled by the provider's own wording, linked. Not by volume.
- **Disclose your interest.** If you work for, or are paid by, a provider you are adding or editing, say so in the pull request. Entries from providers are welcome; undisclosed promotion is not.
- **Keep it on topic.** No advertising, referral links or affiliate codes.

## What is not acceptable

- Harassment, discriminatory language, or sexualised comments of any kind.
- Publishing someone's private information.
- Knowingly submitting false limits, fabricated sources, or API keys and other credentials.
- Repeatedly reopening a settled question without new evidence.

## Enforcement

The maintainer may edit or remove comments, close or lock threads, and block accounts that break these rules. Obvious spam is removed without warning; for everything else, expect a note explaining what the problem was first.

## Reporting

If someone's behaviour here is a problem, report it privately through GitHub's "Report content" option on the comment, or contact the maintainer via the profile at <https://github.com/IdoY12>. Reports are kept confidential.

## Scope

These rules apply to this repository: issues, pull requests, commit messages and review comments.
